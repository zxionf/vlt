# 20 — 同步功能集成到设置页面 — 2026-07-25

## 概述
在设置页面添加服务器同步功能，含服务器地址配置、设备注册、一键同步（上传+下拉）。

## SettingScreen 新增内容

```
┌─ 服务器同步 ────────────────────┐
│ [服务器地址 http://10.0.2.2:8080] │
│ [注册设备]  [同步]                │
│ 状态: 上传成功; 下载 3 条         │
└─────────────────────────────────┘
```

- 服务器地址可编辑，自动更新 `SyncManager.baseUrl`
- "注册设备" → POST `/api/devices/register`（发送 deviceId + pubKey + encryptedDataKey）
- "同步" → 并行上传所有记录 + 下拉服务器新记录，状态汇总显示
- 上次同步时间戳存 `sync_prefs` SharedPreferences 用于增量同步
