## Phase 3 — 服务器同步

### 技术选型：Rust + Actix-web + SQLite

### 服务器 API

| 端点 | 方法 | 说明 |
|------|------|------|
| `/api/health` | GET | 健康检查 |
| `/api/devices/register` | POST | 注册设备（deviceId, publicKey, encryptedDataKey） |
| `/api/devices/{id}` | GET | 查询设备信息 |
| `/api/devices/pending` | GET | 待授权设备列表 |
| `/api/devices/authorize` | POST | 授权新设备（写入 encryptedDataKey） |
| `/api/sync/push` | POST | 批量上传密码记录 |
| `/api/sync/pull/{since}` | GET | 拉取更新的密码记录（时间戳增量） |

### 数据库表
- `devices` — 设备注册信息
- `pending_authorizations` — 设备授权请求
- `password_records` — 加密密码记录

### 文件
| 文件 | 用途 |
|------|------|
| `server/Cargo.toml` | 依赖：actix-web 4, sqlx, serde, uuid, chrono |
| `server/src/main.rs` | 入口：连接 SQLite，CORS 全开，绑定 0.0.0.0:8080 |
| `server/src/models.rs` | 请求/响应结构体 |
| `server/src/db.rs` | 数据库迁移（建表） |
| `server/src/routes.rs` | API 端点实现 |
