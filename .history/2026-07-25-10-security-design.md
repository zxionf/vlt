# 10 — 安全架构方案选择记录 — 2026-07-25

## 方案评估与选择

| 方案 | 密钥大小 | 速度 | 安全性 | 选择 |

| EC P-256 | 256-bit | 快 | 等效 RSA-3072 | |
| RSA-3072 | 3072-bit | 中 | 高 | **✅ 选择** |
| RSA-4096 | 4096-bit | 慢 | 最高 | |

### ② 主密码验证机制

### ⑤ 私钥存储

多端同步需要私钥可导出 → **应用内加密存储**（非 Android Keystore）。

### ⑥ 生物识别 + 主密码并存

| 方案 | 流程 | 选择 |
|------|------|------|
| A: 二选一 | 设置里切换 | |
| B: 两层 | 指纹解锁→再输主密码 | |
| C: 指纹代理 | 主密码加密密钥存 Keystore，指纹通过后释放 | **✅ 选择** |

### ⑦ 字段加密粒度

| 字段 | 加密 | 原因 |
|------|------|------|
| title | 明文 | 列表、搜索 |
| username | 明文 | 搜索、副标题 |
| url | 明文 | 搜索 |
| notes | 加密 | 敏感信息 |
| encryptedPasswd | 加密 | 核心数据 |

### ⑧ 主密码强度

不强制定规则，但 UI 给出建议：**推荐 8 位以上，含大小写+数字**。

### ⑨ 主密码存活策略

配合指纹（方案⑥-C），密钥在 Keystore，内存中不长期持有明文。

## 最终完整方案

```
首次启动流程：
  设置主密码 + 密码提示
  → PBKDF2 派生 AES-256 密钥（masterKey）
  → 生成 RSA-3072 密钥对
  → 公钥存 key_pair 表
  → 私钥用 masterKey（AES-GCM）加密后存文件
  → 加密一条 magic text 存数据库（用于验证）
  → masterKey 存入 Android Keystore（指纹保护）

日常使用流程：
  指纹验证
  → Keystore 释放 masterKey
  → 用 masterKey 解密数据
  → 显示密码、加密新密码

多端同步流程（未来）：
  设备A的数据 → 用设备B的公钥加密 → 同步 → 设备B用私钥解密
```
