# 22 — Rust CLI 密码管理器 `vlt` — 2026-07-26

## 概述
创建 Rust CLI 版本密码管理器，命令风格 `vlt <subcommand> [flags]`。

## 命令

| 命令 | 用法 | 说明 |
|------|------|------|
| `vlt init` | | 首次设置主密码 + 密码提示 |
| `vlt add -t google -u user -p passwd` | `-t` title, `-u` uname, `-p` passwd, `-U` url, `-n` notes | 添加密码记录（缺失字段交互补全） |
| `vlt list` | | 列出所有记录（ID前8位+标题+用户名） |
| `vlt get <id前缀>` | | 查看详情（含解密密码） |
| `vlt edit <id前缀> -p newpass` | | 编辑记录 |
| `vlt delete <id前缀>` | | 删除（确认提示） |
| `vlt upload` | | 同步到服务器（接口预留） |
| `vlt download` | | 从服务器下载（接口预留） |

## 技术栈

- **CLI**: clap 4 (derive)
- **数据库**: rusqlite (bundled SQLite)
- **加密**: PBKDF2-HMAC-SHA512 (600K iter) + AES-256-GCM
- **交互**: rpassword + dialoguer
- **数据库文件**: `~/.vlt/vault.db`

## 安全对齐

与 Android 端完全一致：
- PBKDF2: SHA-512, 600,000 迭代, 32-byte salt
- AES-256-GCM: 12-byte nonce, 128-bit tag
- 存储格式: `base64(nonce):base64(ciphertext)`
- Magic Text 验证: `PWD_MASTER_VERIFY_OK`
- 主密码不入数据库，只存 salt + magic text 密文
