# 12 — NPE 闪退修复：CryptoSession.key 未赋值 — 2026-07-25

## 现象
添加新密码记录时闪退，Logcat 显示：
```
NullPointerException at CryptoSession.encrypt(CryptoSession.kt:9)
```

## 根因
`CryptoSession.key` 默认为 null，仅首次设置主密码时在 `SetMasterPasswordScreen` 中赋值。后续启动 + 生物识别解锁后从未加载密钥，导致 `CreatePasswordScreen.save()` 调用 `CryptoSession.encrypt()` 时 `key!!` 抛 NPE。

## 修复

| 文件 | 改动 |
|------|------|
| `SetMasterPasswordScreen.kt` | 密钥派生后立即 `CryptoSession.key = aesKey` |
| `CryptoSession.kt` | 新增 `verifyAndLoad(context, password)` suspend 方法：读 salt → 派生 → 验证 magic text → 赋值 key |
| `MainActivity.kt` | 生物识别成功后不直接解锁，改为弹出主密码输入 AlertDialog；验证通过才加载 key 并解锁；新增 `needsPasswordInput` 状态 |
| `MainActivity.kt` | 无生物识别设备时跳过验证，仍直接解锁（降级处理） |
